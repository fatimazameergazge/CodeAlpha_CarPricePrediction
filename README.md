# 🚗 Car Price Prediction

## Overview
A machine learning project that predicts the selling price 
of used cars based on features like present price, mileage, 
fuel type, transmission, and car age using Linear Regression.

## Dataset
- Source: CodeAlpha (Car Data CSV)
- 301 samples
- Features: Car Name, Year, Selling Price, Present Price,
  Driven KMs, Fuel Type, Selling Type, Transmission, Owner

## Model
- Algorithm: Linear Regression
- Test Size: 20%
- Evaluation: R² Score & RMSE

## Results
- Successfully predicted car prices based on key features
- Car age and present price were the most influential features

## Tools & Libraries
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## How to Run
1. Download `car data.csv` from the repository
2. Open `Car_Price_Prediction.ipynb` in Google Colab
3. Upload the CSV when prompted
4. Run all cells top to bottom
